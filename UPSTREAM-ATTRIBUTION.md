# Strinova upstream attribution

Strinova is the product name for this extensible framework project. It is derived from
[StraviaPlatform](https://github.com/Stravia-AI/StraviaPlatform) v0.7.5,
commit `aa69767523da8010cbbbd306bded13f212ec52e2`.

The upstream project remains the source of the AGPL-3.0-only licensed platform
code and its release history. Strinova adds the host platform-plugin framework,
overlay integration, UI adjustments and compatibility patches maintained in its
overlay repository. Upstream names remain only where they identify the source
project, protocol, crate namespace or an existing compatibility contract.
